欢迎来到我的博客！

这是我的第一篇博客文章。我会在这里分享技术心得、生活感悟，以及其他有趣的内容。

博客功能

这个博客支持以下功能：

  • 📝 文章发布 - 使用 Markdown 编写，简洁高效
  • 💬 留言评论 - 基于 Giscus 的评论系统
  • 🔍 全文搜索 - 快速找到你想要的内容
  • 🖼️ 图片展示 - 支持各种图片格式
  • 📱 响应式设计 - 在手机和电脑上都有良好体验

关于评论系统

评论功能使用 Giscus，它基于 GitHub Discussions。这意味着：

  • 完全免费，没有广告
  • 评论数据存储在 GitHub，安全可靠
  • 支持 Markdown 格式
  • 可以使用 GitHub 账号直接登录评论

稍后我会详细说明如何配置评论系统。

图片上传方案

我使用的是 GitHub + jsDelivr 的免费图床方案：

  1. 将图片上传到 GitHub 仓库
  2. 通过 jsDelivr CDN 加速访问
  3. 使用 PicGo 工具可以一键上传

这种方式完全免费，而且速度快、稳定性好。
